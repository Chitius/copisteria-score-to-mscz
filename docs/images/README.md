# 演示图片

根目录 `README.md` 使用两张图，分别回答“流水线修好了什么”和“交付后怎样核对”。

| 文件 | 内容 | 制作方式 |
|---|---|---|
| `demo-omr-xml.png` | 《Sincerely》m16–18：原谱、OMR 原始 MusicXML 与修复后 MusicXML 的对照 | 两份 XML 都用 MuseScore 渲染；各取同一小节范围，原谱跨页的两条谱表放在首组 |
| `demo-3-final.png` | 小节级 review 对照页 | `review/sheets/<page>.compare.png`，左侧为最终交付 `score.mscz` 按扫描页分页渲染、右侧为原始扫描 |

## 替换原则

- OMR 演示必须同时给出原谱，并渲染**原始 XML**，不要用符号置信度热图代替；修复前后应使用同一小节范围和同一渲染器。
- 局部对照优先取一行谱，选择能直接看出结构或排版差异的片段；原谱跨页时可把对应谱表放在同一组并注明页码。
- 整页图留给 review 部分，并保留左右两列、同色同号的小节和图例。
- 图片使用 PNG 并控制文件大小；不要写入本机路径、运行日期或开发过程信息。
